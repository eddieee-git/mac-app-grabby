Grabby의 첫 배포판이에요. 필요한 기능만 담은 macOS 메뉴바 화면 캡처 앱이에요.

## 설치

1. 아래 **Grabby-0.2.0.dmg**를 내려받아 열고, Grabby를 응용 프로그램 폴더로 끌어다 놓으세요.
2. 처음 열 때 "확인되지 않은 개발자" 경고가 나오면, 응용 프로그램 폴더에서 Grabby를 **오른쪽 클릭 → 열기**를 누르세요.
3. 처음 캡처할 때 화면 기록 권한을 켜고 Grabby를 다시 실행하세요.

자세한 사용법은 [README](https://github.com/eddieee-git/Grabby#readme)를 보세요.

## 주요 기능

- **캡처**: 영역(⌃⌘1), 마지막 영역 다시(⌃⌘2), 전체 화면(⌃⌘3), 화이트보드(⌃⌘₩), 타이머(3·5·10초). 클릭하면 창 하나를 고르고, 돋보기로 픽셀 단위로 맞추고, C로 색을 복사해요.
- **바로 편집**: 고른 자리에서 화살표·직선·네모·동그라미·자유그리기·텍스트·번호·형광펜·모자이크·흐리게. 그린 표시는 다시 골라 옮기고 지우고 색을 바꿀 수 있어요.
- **마치기**: 복사(↩), 저장(⌘S), 화면에 띄우기(⌘P), 글자 복사(⌘T, 한국어·영어 OCR), 꾸며서 복사(⌘B).
- **탭 창**: 캡처가 탭으로 쌓이고, 나중에 다시 고치고, 글자·메모로 검색하고, ★ 고정하고, 모두 저장·모두 닫기를 할 수 있어요.
- **설정**: 한국어/English, 라이트/다크, 단축키 바꾸기, 기본 색·굵기, 저장 폴더·형식.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 처음 열 때 경고가 나와요.
- 여러 모니터에 걸친 영역 하나를 고르는 기능과 스크롤 캡처는 없어요.
