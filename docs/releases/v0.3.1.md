다음 업데이트부터 메뉴에서 바로 설치할 수 있게 하고, 캡처를 닫아도 탭에 남도록 바꾼 버전이에요.

## 설치와 업데이트

1. 아래 **Grabby-0.3.1.dmg**를 내려받아 열고, Grabby를 응용 프로그램 폴더로 끌어다 놓으세요(이전 버전이 있으면 덮어쓰기).
2. 처음 열 때 경고가 나오면 **완료**를 누른 뒤:
   - macOS 15 이상: 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**
   - macOS 14: 응용 프로그램 폴더에서 Grabby를 **오른쪽 클릭 → 열기**
3. 화면 기록 권한을 다시 물으면, 목록에서 Grabby를 한 번 껐다 켜고 **켰으면 다시 시작**을 누르세요.

이번이 직접 받아 덮어쓰는 마지막 업데이트예요. 다음 버전부터는 아래 원클릭 업데이트를 쓸 수 있어요.

## 새 기능: 메뉴에서 업데이트

- 설정 → **새 버전이 나오면 알려 주기**를 켜 두면, 새 버전이 나왔을 때 메뉴바 메뉴 맨 위에 **새 버전 설치…**가 생겨요.
- 누르면 새 dmg를 내려받아 확인하고, Grabby를 바꿔 넣은 뒤 다시 시작해요. 이렇게 받으면 "열 수 없음" 경고가 뜨지 않아요.
- GitHub 릴리스의 SHA-256, 앱 번들 ID·버전, 코드 서명이 모두 맞을 때만 바꾸고, 하나라도 다르면 설치하지 않아요.
- dmg 안에서 바로 실행 중이거나 응용 프로그램 폴더에 쓸 수 없으면 릴리스 페이지를 열어요.

## 바뀐 점

- **Esc로 닫아도 탭에 남아요**: 영역을 고른 뒤 Esc나 ✕로 닫으면 클립보드는 그대로 두고 탭에만 넣어요. 설정 → **Esc로 닫아도 탭에 남기기**에서 끌 수 있어요. QR 읽기와 빈 화이트보드는 남기지 않아요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나오고, 업데이트 뒤 화면 기록 권한을 다시 물을 수 있어요.
