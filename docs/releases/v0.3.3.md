업데이트를 다섯 앱 공통 방식으로 바꾸고, 새 버전 자동 확인을 기본으로 켠 버전이에요. 캡처 기능은 그대로예요.

## 설치와 업데이트

- **0.3.1이나 0.3.2를 쓰고 있다면**: 설정에서 "새 버전이 나오면 알려 주기"를 켜 두었으면 메뉴바 메뉴의 **새 버전 설치…**로 바로 업데이트돼요. **켜지 않았다면 이번 한 번만** 아래 **Grabby-0.3.3.dmg**를 내려받아 응용 프로그램 폴더에 덮어써 주세요. 0.3.3부터는 자동 확인이 기본으로 켜져 있어요.
- **처음 설치하거나 0.3.0 이전이라면**: 아래 **Grabby-0.3.3.dmg**를 내려받아 Grabby를 응용 프로그램 폴더로 끌어다 놓으세요(덮어쓰기). 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).
- 업데이트 뒤 화면 기록 권한이 풀렸으면 Grabby가 바로 알려 줘요. 목록에서 Grabby를 한 번 껐다 켜고 **켰으면 다시 시작**을 누르세요.

## 바뀐 점

- **자동 확인 기본 켬**: 하루 한 번 새 버전을 확인해요. 전에 직접 끈 사람은 그대로 꺼져 있어요.
- **자동 설치는 따로**: 설정의 업데이트 칸에서 켜면 Grabby를 쓰지 않을 때 알아서 설치해요(기본 끔). **지금 확인**으로 바로 확인할 수도 있어요.
- **업데이트 확인 강화**: 받은 파일의 서명, SHA-256, 번들 ID, 버전, 코드 서명을 모두 확인한 뒤에만 설치해요. GitHub 요청 한도에 걸리면 릴리스 페이지로 최신 버전을 알아내요.
- **정보 칸**: 설정 → 정보에 GitHub, 변경 기록, 문제 알리기, 같은 사람이 만든 다른 앱 링크가 생겼어요.
- 메뉴바 메뉴 순서를 설정… → 업데이트 → 시작 안내 → 종료로 맞췄어요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나오고, 업데이트 뒤 화면 기록 권한을 다시 물을 수 있어요.

## English

Grabby 0.3.3 moves updates to the updater shared by all five apps and turns automatic update checks on by default. Capturing is unchanged.

**Installing and updating**
- On 0.3.1 or 0.3.2 with update alerts on, use **Install Version…** in the menu bar menu. **If you never turned them on, download Grabby-0.3.3.dmg below and replace Grabby in Applications just this once.** From 0.3.3, automatic checks are on by default.
- New installs or 0.3.0 and earlier: download **Grabby-0.3.3.dmg** below and drag Grabby into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).
- If Screen Recording permission was reset by the update, Grabby tells you right away. Turn Grabby off and on in the list, then click **Restart After Turning On**.

**Changed**
- **Automatic checks on by default**: once a day. If you had turned them off, they stay off.
- **Automatic installs are separate**: turn them on in Settings to install while Grabby is idle (off by default), or use **Check Now**.
- **Stronger update checks**: installs only after the signature, SHA-256, bundle ID, version, and code signature are verified; the releases page is used when GitHub's rate limit is hit.
- **About**: Settings → About links to GitHub, the changelog, problem reports, and other apps by the same developer.
- Menu bar menu order: Settings… → Updates → Getting Started → Quit.

**Known limits**
- Apple silicon Macs with macOS 14 or later only.
- Without an Apple developer signature, macOS warns on first launch from the dmg, and may ask for Screen Recording permission again after updates.
